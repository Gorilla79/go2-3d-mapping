# Figures

Two kinds of figure are used on the site. Each is labelled where it appears.

## Schematic (`*.svg`)

Hand-authored vector diagrams of algorithm concepts. They contain **no measured
data**, and every file carries a visible `SCHEMATIC` label. They are generated by
`scripts/figures/fig1.py` and `fig2.py` (`python3 scripts/figures/fig1.py`).
Captions and alt text are in `src/data/figures.ts`. Sources for the statements
are listed in `docs/ALGORITHM_SOURCES.md`.

| File | Topic |
|---|---|
| `system-overview.svg` | Sensor platform and data flow |
| `deskew-comparison.svg` | Motion distortion and deskew. **SCHEMATIC**: no raw sweep comparison exists on the publishing host |
| `map-accumulation.svg` | Scan insertion with estimated poses |
| `lod-concept.svg` | Multi-resolution web derivatives (not an octree) |
| `fastlio-pipeline.svg` | FAST-LIO processing flow |
| `fastlio-point-plane.svg` | Point-to-plane residual |
| `fastlio-state-update.svg` | Iterated error-state update |
| `liosam-pipeline.svg` | LIO-SAM processing flow |
| `liosam-features.svg` | Edge / planar features |
| `liosam-factor-graph.svg` | Factor graph with loop closure (GPS shown as not used) |

## Data-derived (`data/*.webp`)

WebGL renders of the **public web derivatives**, produced by the site's own
viewer with `scripts/render-data-figures.mjs`. Nothing is drawn by hand. For
each image, `data/figures.json` records:
- source LOD files and their SHA-256
- floor and algorithm
- colour mode and point size
- camera position and target
- render date

These images are previews, not the scientific dataset. The 4F images without a
trajectory are the default; the trajectory image is used only on the LIO-SAM
method page.
